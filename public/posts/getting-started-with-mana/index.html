Analyzing Dylib Injection on macOS

January 8, 2026 • 155 words • 1 min
macOS Red Teaming Injection Objective-C

Dylib injection remains a classic technique for hooking into running processes on macOS. In this post, we will look at how to force a dynamic library into a target process using DYLD_INSERT_LIBRARIES.

The Vulnerable Target

First, let’s identify a target. We are looking for binaries that do not have the Hardened Runtime enabled or possess specific entitlements that allow library loading.

You can check entitlements using codesign:

# Check entitlements of a binary
codesign -d --entitlements :- /Applications/VulnerableApp.app


package main

import (
    "fmt"
    "os"
    "path/filepath"
)

func findLaunchAgents() ([]string, error) {
    var agents []string
    root := "/Library/LaunchAgents"

    err := filepath.Walk(root, func(path string, info os.FileInfo, err error) error {
        if filepath.Ext(path) == ".plist" {
            agents = append(agents, path)
        }
        return nil
    })

    if err != nil {
        return nil, err
    }
    return agents, nil
}

func main() {
    agents, _ := findLaunchAgents()
    for _, agent := range agents {
        fmt.Printf("[*] Found Agent: %s\n", agent)
    }
}
